# TruckShowroom — نسخه MVP

اپلیکیشن فارسی مدیریت نمایشگاه خودروهای سنگین.

این نسخه برای Build آنلاین با GitHub Actions آماده شده است و برای ساخت APK به Android Studio روی کامپیوتر کاربر نیاز ندارد.

## Build
Workflow:
`.github/workflows/build-apk.yml`

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## امکانات
- داشبورد نمایشگاه
- ثبت و ویرایش خودرو
- خودروهای سنگین با انواع مختلف
- وضعیت موجود/رزرو/فروخته‌شده
- جستجو و فیلتر
- ثبت مشتری
- حالت کاتالوگ مشتری
- ذخیره محلی
- آماده‌سازی ساختار برای Cloud Sync
